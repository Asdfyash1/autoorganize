# Changelog

All notable changes to AutoOrganize will be documented in this file.

## [1.0.0] - 2025-04-29

### Added
- Smart file organizer CLI with Rich terminal output
- Auto-sort files by type, date, or custom YAML rules
- Real-time directory watch mode with Watchdog
- Dry-run mode for safe previews
- Undo support to reverse organization
- Configurable YAML rules for custom sorting
- AI-powered smart categorization (reads file contents)
- AI-powered filename suggestions
- Multi-provider AI support: OpenAI, Google Gemini, NVIDIA
- Automatic API key detection with fallback chain
- Comprehensive test suite (6 tests)
- GitHub Actions CI with Python 3.9-3.12 matrix
